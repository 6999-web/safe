## 3. 注册与登录

1. 打开平台前端，点击右上角“登录平台”。
2. 体验已有角色时，点击“白帽研究员”“企业管理员”或“平台管理员”，再点击“验证并进入平台”。
3. 注册新白帽时切换到“研究员注册”，输入用户名、昵称、密码和可选邮箱。
4. 用户名只能使用 4-30 位字母、数字或下划线，密码长度为 8-64 位，昵称不能为空。
5. 新注册账号固定为白帽研究员角色，注册成功后自动登录并进入白帽中心。

## 4. 白帽研究员流程

1. 登录白帽账号，进入“任务大厅”。
2. 按任务类型或关键词筛选企业授权任务，核对目标资产、测试周期和参与范围。
3. 点击“申请参与”。同一账号不能重复申请同一任务。
4. 在“白帽中心”查看等级、积分、排名、我的任务和漏洞记录。
5. 执行任务期间按日期提交日报；同一任务同一天只能提交一份日报。
6. 提交漏洞时填写影响资产、复现步骤、严重等级和 CVSS 分数。
7. 企业确认漏洞后，系统按低危 10 分、中危 50 分、高危 200 分、严重 500 分发放积分。
8. 在“安全社区”浏览或发布技术文章，并参与评论。

所有测试必须严格限制在任务声明的授权资产、授权时间和授权方法内。

## 5. 企业安全管理员流程

1. 使用 `acme` 登录，系统自动进入“企业中心”。
2. 点击“创建任务”，填写任务名称、类型、描述、授权目标、周期、奖励和人数上限。
3. 在“任务管理”查看本企业任务。
4. 在“漏洞管理”查看白帽提交的漏洞，完成确认或驳回。
5. 确认漏洞会在同一事务内更新审核状态、积分流水、用户总积分和等级。
6. 通过任务日报接口查看参与成员的每日进度。

企业只能管理本企业的任务、日报和漏洞，不能审核其他企业的数据。

## 6. 平台管理员流程

1. 使用 `admin` 登录。
2. 管理员可读取平台运营总览、全部任务和全部漏洞。
3. 管理接口必须携带登录后获得的 JWT，普通白帽账号访问会返回 `403`。

当前项目是可运行 MVP。完整的企业审核、用户封禁、内容审核、积分规则后台和审计日志仍属于正式运营前需要继续建设的管理能力。

## 7. 常见状态码

| 状态码 | 含义 | 处理方式 |
|---|---|---|
| `400` | 输入或业务条件不合法 | 查看页面提示，例如用户名已存在、日期错误或账号密码错误 |
| `401` | 未登录或令牌过期 | 重新登录 |
| `403` | 当前角色无权限 | 使用正确角色账号，或确认数据归属 |
| `409` | 重复提交 | 不要重复申请同一任务、提交同日重复日报或创建重复数据 |
| `500` | 服务端异常 | 记录操作时间并检查后端、PostgreSQL 和网关日志 |

浏览器开发者工具把 `400/401/403/409` 显示为 `Failed to load resource`，并不等同于服务器崩溃。页面会同步显示后端返回的具体业务原因。

## 8. API 登录示例

```bash
curl -X POST http://101.33.210.169:39999/api/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"whitehat","password":"WhResearch@2026!3Qx7"}'
```

后续受保护请求需要添加响应中的令牌：

```bash
curl http://101.33.210.169:39999/api/user/profile \
  -H 'Authorization: Bearer <JWT_TOKEN>'
```
